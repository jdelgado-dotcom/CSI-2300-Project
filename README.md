# CSI-2300-Project

Project Name: Study Quiz Application

Team Name: None

Team Members: Josue Delgado

Description: A quiz app where the user will answer questions and be evaluated with a score at the end. Arrays will eventually be used to store questions and answers. My reason for building it is that I like to quiz myself on material I learned before an exam, and I thought this might be another way to do it. Since the questions would be made by me, it would be a much more personalized quiz than if I were to find one online and thus would only focus on the sort of questions I struggle with.
